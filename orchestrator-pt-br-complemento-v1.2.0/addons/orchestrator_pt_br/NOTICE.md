# Procedência da tradução — versão 1.2.0

Orchestrator é desenvolvido por Crater Crash Studios e seus colaboradores:
https://github.com/CraterCrash/godot-orchestrator/tree/v2.5.stable

Este complemento independente acrescenta apresentação em português do Brasil ao editor. Não modifica as bibliotecas originais. Código do complemento disponibilizado sob Apache 2.0; veja LICENSE. Os créditos e a licença do pacote original são preservados no pacote completo.

`pt_BR.json` e `revisado_pt_BR.json` contêm traduções e revisões específicas da interface. `api_pt_BR.json` contém traduções assistidas por modelo, produzidas localmente a partir de nomes públicos da API da Godot 4.7.2, com normalização de rótulos. Termos especializados desse catálogo amplo não foram todos revisados individualmente. Entradas revisadas têm prioridade sobre o catálogo assistido.

Na versão 1.2.0 foram revisados os rótulos dos 117 métodos estáticos da API inventariada, os menus de contexto e os casos apontados pelo usuário. `modelos_pt_BR.json` contém traduções de frases dinâmicas com marcadores preservados. Alguns nomes de classes recebem uma explicação em português acompanhada do identificador original; os identificadores armazenados nos grafos não são substituídos.

Modelo usado somente na preparação: English → Portuguese (Brazil), versão 1.9, distribuído pelo Argos Translate. A execução local utilizou CTranslate2 e SentencePiece. Nenhum desses programas, pesos de modelo ou conexão com serviço de tradução é necessário ao usar o complemento.

- Índice oficial: https://github.com/argosopentech/argospm-index
- Pacote do modelo: https://argos-net.com/v1/translate-en_pb-1_9.argosmodel
- Modelo original OPUS-MT, licença CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
- Crédito: Jörg Tiedemann e Santhosh Thottingal. “OPUS-MT — Building open translation services for the World”. Proceedings of the 22nd Annual Conference of the European Association for Machine Translation (EAMT), Lisboa, 2020.

Os pesos do modelo não são redistribuídos com o complemento. O processamento foi local; arquivos e conteúdo dos projetos do usuário não foram enviados a serviços de tradução.
